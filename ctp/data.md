# Data tables

Every dataset ("board") tested in the project — **29 in total**: 7 original boards, 21 boards derived
from the R **CASdatasets** package, and the WA workers-compensation severity board. The source of truth
is the `PROFILES` dict in [scripts/build_ctp_dashboard.py](../scripts/build_ctp_dashboard.py);
locking/cleaning logic is in [scripts/prep_casdatasets.py](../scripts/prep_casdatasets.py),
[scripts/prep_additional_datasets.py](../scripts/prep_additional_datasets.py), and the per-dataset
`scripts/prep_<key>.py`. Row counts `n` are the **locked** counts; the dashboard `row_cap` may subsample
further at run time (noted per board).

**Standard layout** ([data/README.md](../data/README.md)): every dataset lives in `data/datasets/<key>/`
with `raw/` (original source, committed), `dictionary.md` + `dataset.yaml` (committed), and
`<key>.csv` + `.meta.json` (the locked modelling table — gitignored, regenerated by prep). To add a new
one, see [docs/adding-a-dataset.md](adding-a-dataset.md) (`scripts/add_dataset.py` scaffolds it).

**Dataset styles:** `severity` (heavy-tail $, Gamma GLM, full EVT/tail metric set) · `frequency` (count,
Poisson GLM, dollar-tail groups greyed) · `dev_triangle` (wide multivariate/development) · `small_grouped`
(n ≤ 210 grouped tariff cells).

**CASdatasets source note** (applies to almost all boards below): the R **CASdatasets** package (Dutang, C.
& Charpentier, A.), companion data to Charpentier's *Computational Actuarial Science with R*. Repo:
https://github.com/dutangc/CASdatasets · manual: https://cas.uqam.ca/pub/web/CASdatasets-manual.pdf.
The raw `.csv/.parquet/.rda` for each now lives in `data/datasets/<key>/raw/` (formerly
`additional-data/<region>/`); the aggregate specs are [docs/casdatasets-specs.md](casdatasets-specs.md)
and [docs/casdatasets-summary.md](casdatasets-summary.md). Tables were read with `pyreadr` (no R/rpy2),
except `ausNSWdriver04` which is an R list extracted via `Rscript`. **Common cleaning:** id/free-text
columns dropped, inflation-restated
`*2007` twins dropped, deterministic redundancies dropped, dates → integer covariates, severity
conditioned on `target>0`, high-card categoricals capped to top-20 + OTHER, big sources locked as a
reproducible seed-2025 stratified 40k draw, target ordered first.

## The 7 original boards

### `ctp` — CTP Severity
- **Data:** NSW Compulsory Third Party impairment lump-sum awards. Target **`Lump Sum`** ($, heavy-tail). Style **severity** (Gamma). **n = 540**, 16 cols. The **only board with substantial informative missingness** (WPI% ~47% missing, Claimant Weekly Income ~42%).
- **Origin / citation:** NSW Personal Injury Commission CTP decisions scraped from **AustLII** (austlii.edu.au) and **LLM-structured** into tabular features. A custom-built project dataset — not CASdatasets or a published paper. Plan: `specs/ctp_severity_pipeline_plan.md`.
- **Source:** custom — `data/datasets/ctp/raw/ctp_impairment_lump_sum.xlsx` → `scripts/build_ctp_severity.py` → `data/datasets/ctp/ctp.csv`.
- **Modifications:** 16 modelling columns selected; cp1252 text artefacts cleaned; **no row dropping, no imputation** (missingness preserved as NaN for the missingness-fidelity metrics). `Non-Economic Loss` + `Future Economic Loss` sum to `Lump Sum` (corr 0.94) — kept in the joint table but **excluded from the downstream GLM** as leakage. `row_cap=None`.

### `swedish` — Swedish Motor Severity (ClaimAmount | claim)
- **Data:** Conditional claim severity, target **`ClaimAmount`** (claims only). Style **severity** (Gamma). **n = 670**, 9 cols. Severity split of the Swedish source.
- **Origin / citation:** Swedish **motorcycle** insurance portfolio 1994–1998 (`mccase.txt`), from **Ohlsson & Johansson (2010), "Non-Life Insurance Pricing with GLMs"** (staff.math.su.se/esbj/GLMbook/mccase.txt); also the reference dataset in the project's paper, **Jamotton & Hainaut (2024)**.
- **Source:** `scripts/build_swedish_severity.py` → `data/datasets/swedish/swedish.csv`.
- **Modifications:** filter `ClaimAmount > 0` (64,548 → 670); keep 8 covariates + target; no missing values.

### `swedish_frequency` — Swedish Motor Frequency (ClaimNb)
- **Data:** Target **`ClaimNb`** (count 0/1/2). Style **frequency** (Poisson). Locked **n = 64,548**, 9 cols; `row_cap=10000` stratified at run time. Frequency split of the same source.
- **Origin / citation:** same as `swedish`. Byte-identical portfolio to CASdatasets `swmotorcycle` (dropped as redundant, below).
- **Source:** `data/datasets/swedish_frequency/swedish_frequency.csv`.
- **Modifications:** `ClaimNb` modelled **categorical** (so copula/PC generators sample it as a marginal); `negbin_tail=["ClaimNb"]`; `disabled_groups=["Tail fidelity","Pricing & reserving"]`.

### `french_tpl_freq` — French Motor TPL Frequency (ClaimNb)
- **Data:** Target **`ClaimNb`** count. Style **frequency** (Poisson). Locked **n = 40,000** (stratified), 11 cols; `row_cap=10000`. Frequency split of French MTPL.
- **Origin / citation:** **freMTPL2freq**, the canonical French motor third-party-liability benchmark (Noll–Salzmann–Wüthrich lineage); obtained from **OpenML data_id 41214** via `sklearn.fetch_openml`.
- **Source:** OpenML 41214 → `data/datasets/french_tpl_freq/french_tpl_freq.csv`.
- **Modifications:** `VehGas` cleaned; `ClaimNb` clipped ≤11 → int; drop `IDpol`; target-first; seed-2025 stratified 40k lock. `negbin_tail=["ClaimNb"]`.

### `french_tpl_sev` — French Motor TPL Severity (ClaimAmount | claim)
- **Data:** Target **`ClaimAmount`** per claim (heavy-tail). Style **severity** (Gamma). Locked **n = 26,444**, 11 cols; `row_cap=1000`. Severity split of French MTPL joined to policy covariates.
- **Origin / citation:** **freMTPL2sev**, **OpenML data_id 41215** (26,639 claims), joined on `IDpol` to freMTPL2freq covariates.
- **Source:** OpenML 41215 + 41214.
- **Modifications:** merge severities to one covariate row per policy (`drop_duplicates("IDpol")`), inner join (~99.3% matched → 26,444), drop `IDpol`, target-first. `heavy_tail=["ClaimAmount"]`.

### `soa_lapse` — SOA Post-Level-Term Lapse (lapse_count)
- **Data:** Target **`lapse_count`** (high-card count 0..1806, modelled **continuous**). Style **frequency** (Poisson). Locked **n = 39,998** (stratified), 12 cols; `row_cap=10000`.
- **Origin / citation:** **SOA (Society of Actuaries) 2014 Post-Level-Term Lapse & Mortality Experience Study** (~345,627 rows), pulled from the **Cellar pins "lapse_study" board** (data.cellar.kasa.ai/lapse_study).
- **Source:** Cellar → `data/datasets/soa_lapse/raw/soa_lapse_study.parquet` → `data/datasets/soa_lapse/soa_lapse.csv`.
- **Modifications:** drop `lapse_amount` (leaks target, corr 0.75), `exposure_amount` (collinear $ twin), `lapse_study_year` (redundant); `lapse_count`→int; stratified 40k lock. `heavy_tail=["lapse_count"]` (vine_gpd extrapolates the count tail with a GPD, rounded by validity); dollar groups greyed, Tail-extrapolation kept. Failure analysis: `docs/soa-lapse-failure-experiments.md`.

### `danish_fire` — Danish Fire Severity (Total loss | MDKK)
- **Data:** Target **`Total`** (Building+Contents+Profits, losses ≥ 1 MDKK, heavy-tail). Style **severity** (Gamma). **n = 2,167**, 6 cols; `row_cap=None` (keep all extremes).
- **Origin / citation:** CASdatasets **`danishmulti`** — multivariate Danish fire losses (Copenhagen Re 1980–1990, 1985 MDKK) — the classic McNeil / Embrechts–Klüppelberg–Mikosch EVT dataset.
- **Source:** `github.com/dutangc/CASdatasets/.../danishmulti.rda` → `data/datasets/danish_fire/danish_fire.csv`.
- **Modifications:** parse `Date`→`Year`,`Month` (only these are GLM covariates; the components would leak the additive Total); keep `Building/Contents/Profits` as the co-loss dependence block; `heavy_tail=["Total","Building","Contents","Profits"]`. With CTP, keeps the Extremal-dependence group at full weight (real tail-dep λ≈0.46).

## Custom board

### `wa_workers_comp` — WA Workers Compensation Severity
- **Data:** Western Australia workers-compensation claims 1985–2005. Target **`incurred_cost`** ($, heavy-tail). Style **severity** (Gamma). **n = 103,261**, 21 cols; `row_cap=1000`. The project's **richest missingness board** — 16 partially-missing columns (weekly_wage 52%, body_location 25%, injury_agency 22%, …), so it exercises the missingness metric set the hardest.
- **Origin / citation:** WorkCover WA scheme extract, prepared and de-identified upstream (TOOCS/ASIC/ASCO code decoding, sentinel-wage removal, leakage/identifier drops — see the dataset's `dictionary.md`). A custom project dataset, no published citation.
- **Source:** `data/datasets/wa_workers_comp/raw/workers_compensation.csv` → `scripts/prep_wa_workers_comp.py` → `data/datasets/wa_workers_comp/wa_workers_comp.csv`.
- **Modifications:** severity view (`incurred_cost > 0`); nullable-int dtypes on the integer covariates; target-first. `total_days_lost` (a claim outcome) is **leakage** — kept in the joint copula table but excluded from the GLM; `initial_estimate` (reserve set at claim creation) is **not** leakage and is a covariate. `severity` (ordinal 1–5) kept numeric. `heavy_tail=["incurred_cost","initial_estimate"]`.

## Dropped / skipped sources (deliberate)

- **`swmotorcycle`** (CASdatasets Swedish motorcycle tariff cells) — **dropped as redundant**: byte-identical to `swedish_motor` (same 64,548 rows; columns just relabelled Zone→Area, Class→RiskClass, Duration→Exposure). Already covered by `swedish` + `swedish_frequency`.
- **`usmedclaim`** (CASdatasets US medical-claims triangle) — **dropped as unusable**: n=36, 12 of 15 columns mostly-missing, negative development increments — below any generator's learnable floor.
- **`fremotor2freq9907`** — not locked (stalls `pyreadr`). **`asiarisk`**, **`freclaimset9207`**, **`fremotorclaim`** — spec names that 404 in current CASdatasets; replaced by `asiacomrisk`, the `freclaimset3*9207` peril-split, and `fremotor2sev9907` respectively.

## Cross-cutting notes

- **29 boards** = 7 originals + 21 CASdatasets boards + WA workers-comp. Freq/sev splits (one source → two boards): swedish, french_tpl, ausprivauto, norauto, bemtpl16, bemtpl97. `beMTPL16` severity is unconditional; the others condition severity on `target>0`.
- **Three boards carry numeric missingness** — `ctp` (5 informative-missing columns), `asiacomrisk` (TIV/DR), and `wa_workers_comp` (16 columns, the richest) — the boards where the Missingness metric group is scored.
- **Per-board privacy metadata** (drives the singling-out / record-disclosure metrics). Each profile carries a `disclosure_unit` and a `quasi_identifiers` set:
  - `disclosure_unit` — `individual` (one row is one person/policy/claim, so a synthetic row reproducing a rare real value-tuple can *single that individual out* → the singling-out test is **on**) or `grouped` (one row is an aggregated cell, so there is no individual to single out → the test is **N/A**). Default `individual`; the **grouped** boards are `swedish`, `swedish_frequency`, `soa_lapse`, `aus_nsw_injury`, `aus_mtpl` (assigned from data granularity — an exposure/count ≫ 1 per row — not from freq/sev style).
  - `quasi_identifiers` — the attacker-knowable columns for the singling-out test; default = the profile's `cat_cols` minus the target, or `[]` to disable. Set to `[]` on `danish_fire` (the loss Year×Month is temporal, not a person-identifier) and `fr_dev_fire` (coarse population bins isolate no business).
- Per-dataset integration notes and failure diagnoses: [docs/additional-actuarial-datasets.md](additional-actuarial-datasets.md). Holistic results by dataset style: [docs/cross-dataset-meta-analysis.md](cross-dataset-meta-analysis.md).
