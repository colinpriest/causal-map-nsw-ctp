Why the order matters here

TabPFN generates columns autoregressively, each one conditioned on the columns before it. In ctp.csv the columns run almost exactly backwards along the causal graph — so the vanilla generator conditions causes on their effects.

Missingness is part of the causal structure

Five columns carry missing values, and none of them are missing at random. Each R node below is an indicator “this field was not recorded in the decision”. The generator must reproduce these mechanisms, not impute them away.
